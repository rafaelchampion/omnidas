# Omnidas

Conversor universal de formatos para Windows, pensado para uso pelo menu de contexto (botão direito).

> Em planejamento. Veja as issues e o épico para o roadmap.

## Visão
- Áudio, vídeo, imagens, documentos, PDF, e-books, legendas, compactados, dados, fontes, 3D e transcrição.
- Conversão rápida com presets (Melhor qualidade, Equilibrado, Menor tamanho, WhatsApp/Web, Arquivamento sem perdas) e presets do usuário.
- Interface que mostra prós e contras de cada configuração.
- 100% local, sem telemetria.

## Stack
C# / .NET 9, WinUI 3, motores open-source (FFmpeg, libvips, Pandoc, 7-Zip) e Pacotes Extras sob demanda.
